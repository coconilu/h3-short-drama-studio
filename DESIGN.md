## Project Brief

Redesign an existing local-first desktop web workbench for solo AI short-drama production. Use a two-level information architecture: global workbench for all projects, recent activity, global generation queue, system health and settings; project workspace for overview, scripts/storyboards, assets, generation, review and delivery. The upper-left brand control must be a real labeled sidebar collapse action, not a decorative icon. System Settings must open a functional settings center for ComfyUI connection, H3 paths, export defaults, storage visibility and UI preferences. Preserve restrained near-black surfaces and warm cinematic gold as the only primary accent. Project cards use real shot thumbnails and production statuses. Desktop-first at 1536px and usable at 900px. All visible icons must have a real interaction or be visually non-interactive.

### Project Brand Adaptation

The catalog Theme's violet accent is intentionally remapped to the existing 镜场 warm gold `#E8A839`. This is a project-specific brand adaptation requested in the brief; it does not change the selected Operational SaaS Console structure, density, typography, or component model. Gold is reserved for current selection, primary actions, progress, and healthy attention states. Errors remain red and service health remains green so operational meaning is not lost.

## Information Architecture

- Global workbench: all projects, recent activity, global generation queue, ComfyUI/GPU/storage health, settings.
- Project workspace: project overview, script and storyboard, project assets, generation queue, review, and delivery.
- The sidebar header has a labeled, accessible collapse control; collapsed state retains tooltips and active state.
- Every visible action icon must be a semantic button with a label or tooltip. Decorative icons must not appear clickable.

## Global Projects First Viewport

- Header: `所有项目`, search, view/sort controls, and one primary `新建项目` action.
- Summary strip: active projects, shots awaiting generation/review, active ComfyUI tasks, storage usage.
- Primary surface: compact project rows or cards using real thumbnails, title, episode, production phase, shot progress, duration, last activity, and a clear `继续制作` action.
- Secondary rail: recent activity and runtime health; no invented analytics charts.
- Empty or blocked states explain the next production action.
