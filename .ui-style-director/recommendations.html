Project brief:Redesign an existing local-first desktop web workbench for solo AI short-drama production. The app needs a global all-projects dashboard, clear separation between workspace-level and project-level navigation, functional settings, a real collapsible sidebar, dense project and shot status views, ComfyUI/GPU health, generation queues, review and delivery. Preserve a restrained dark cinematic identity with warm gold accent, but prioritize professional tool clarity, actionable icons, compact information density, accessibility, and a production operations feel. React desktop-first, responsive at 900px.
